- `npm run build`：TypeScript 编译通过。
- `npm test`：19 项通过。覆盖原子并发门控、自己的消息与 override、幂等竞争/载荷冲突/控制信息重放、双向分页、首次截断/空频道初始化、显式单调读取确认、跨频道鉴权/引用/点名、输入与字节边界、管理员 Origin/安全 Cookie/到期、数据库重启、long poll 提交/超时/断开/撤销/关闭。

- `npm audit --omit=dev`：生产依赖 0 漏洞；Fastify 固定 5.12.5。
